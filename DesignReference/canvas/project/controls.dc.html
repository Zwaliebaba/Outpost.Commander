Controls

Every binding the Controls window lists (28 actions under 3 headings), grouped as the window groups them. The window is built from KeyBindings.h, so it cannot name a key the code does not read (ADR-068 d4).

  • P is taken by the production window, so patrol is T (ADR-059 §Decision 7, KeyBindings.h:28).
  • What arms the next click. A, H and T each arm the next left-click and replace whatever was armed before. A press on the ground then gives the order. Right-click or Escape cancels it (PlayerControls.cpp:107-121, 180-206, 291-292, 362-367).
  • Ctrl blocks the order keys. A, H, T and S act only without Ctrl (PlayerControls.cpp:369-383).
